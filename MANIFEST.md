# Manifest

- `SKILL.md` — primary Agent Skills entrypoint.
- `README.md` — installation and usage instructions.
- `AGENTS.md` — always-on agent guidance when used as a repository.
- `references/d2-language-reference.md` — compact D2 syntax reference.
- `references/diagram-pattern-cookbook.md` — practical diagram recipes.
- `references/conversion-guide.md` — Mermaid/PlantUML/Graphviz/prose conversion guidance.
- `references/rendering-and-validation.md` — CLI and helper script guidance.
- `references/troubleshooting.md` — common mistakes and fixes.
- `references/source-notes.md` — research links.
- `templates/*.d2` — starter diagrams.
- `scripts/check_d2.sh` — validate by rendering to temporary SVG.
- `scripts/render_d2.sh` — render to requested output format.
- `scripts/scaffold_d2.py` — list/copy starter templates.
- `tests/smoke.d2` — small validation diagram.
- `agents/openai.yaml` — optional Codex/plugin metadata.
- `LICENSE` — MIT license.
- `.gitignore` — excludes rendered diagram outputs and local cruft.
